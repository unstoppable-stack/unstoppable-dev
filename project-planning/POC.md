
### **scope (what to build first)**

**POC goal**

“From zero → scaffold app → run it locally → agent can extend it.”


**POC includes**

1. Simple website with:

• Landing

• Getting Started

• Docs skeleton (even if incomplete)

2. CLI that scaffolds **one template** (keep it tight):

• Example: “Local-first starter” using Bare + Pear + minimal Holepunch wiring

3. Agent pack that can:

• explain the scaffolded architecture

• add a new feature (e.g., a basic module or screen) without breaking conventions


**POC explicitly excludes**

• Full Unstoppable Auth

• Paid Cloud services

• Full “QVAC assistant” UX
