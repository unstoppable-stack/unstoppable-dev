**Target user**

A dev who wants to ship local-first / p2p / unstoppable apps without hand-wiring 8 libraries.

**Flow (end-to-end)**

1. User visits website → sees value + examples.

2. Click **Get Started** → installs CLI (or downloads plugin).

3. Runs create-unstoppable-app (or similar).

4. CLI asks:

• Editor/assistant: Claude / Cursor / OpenCode

• App type: (starter templates)

• Modules to include: QVAC, Pear, Unstoppable Auth, Expo Bare, etc.

5. CLI scaffolds project + configures “agent instructions/skills” for the chosen tool.

6. User opens in their editor and starts building with the agent.
