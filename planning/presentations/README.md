# Presentations

Each subfolder is a presentation grouped by date and name.

## Convention

```
presentations/
├── YYYY-MM-<short-name>/
│   ├── deck-outline.md      # Slide-by-slide outline
│   ├── speaker-notes.md     # Detailed speaker notes
│   ├── one-pager.md         # Quick summary handout
│   └── ...                  # HTML decks, short versions, etc.
```
