# Developer preview independent pilot

Prepared 5 October 2026. No participant results have been collected.

Recruit three developers who did not implement this project. Use the exact candidate artifact and website preview recorded in the release manifest. Do not give private setup instructions. A facilitator may record a blocker, but any intervention makes that attempt assisted and requires a fresh retest after correction.

## Participant task

Follow Getting Started, configure your Codex workspace, create the desktop local-AI app, install and open it. Load the model and ask a coffee question. Save `morning` with value `one oat latte`, close and reopen the app, and fetch `morning`. Ask your coding assistant to change the saved-order button label to “Save order” and verify the visible change. Disconnect external networking after the model is cached and repeat an AI question. Record any unexpected behavior rather than editing source to bypass it.

Peer communication must be tested separately once the maintained example exposes an observable peer interaction; a “network ready” label is insufficient evidence.
