# Architecture and ownership invariants for Unstoppable apps

Discover the target app and inspect its .unstoppable/project.json, package.json and entrypoints first. For a new app, inspect the installed CLI catalog. Read [the reference index](resources/INDEX.md), then only the matching note. Resources resolve relative to this skill, not the app or workspace. Installed contracts and version-matched SDK types take precedence over generic examples.
