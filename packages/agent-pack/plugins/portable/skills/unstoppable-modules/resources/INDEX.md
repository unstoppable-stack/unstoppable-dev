# Runtime boundaries and integration notes for Unstoppable stack modules

Read only the reference relevant to the selected app and task.

- [autobase](autobase.mdc): Autobase: low-level multi-writer consensus for Hypercore. Prefer Autobee for new work.
- [autobee](autobee.mdc): Autobee: multi-writer Hyperbee — the recommended convergent P2P store
- [bare](bare.mdc): Bare runtime: minimal JS runtime for P2P and embedded use
- [corestore](corestore.mdc): Corestore: manage multiple Hypercores from a single storage backend
- [expo-bare](expo-bare.mdc): Experimental mobile host/worklet boundaries and coupled native compatibility.
- [hyperbee](hyperbee.mdc): Hyperbee: sorted key-value store built on Hypercore
- [hypercore](hypercore.mdc): Hypercore: append-only log, the foundation of all Holepunch data structures
- [hyperdb](hyperdb.mdc): HyperDB: P2P key-value database with schema, indexes, and multi-writer support
- [hyperdht](hyperdht.mdc): HyperDHT: distributed hash table for peer discovery and NAT traversal
- [hyperdrive](hyperdrive.mdc): Hyperdrive: P2P file storage, sharing, and mirroring
- [hyperswarm](hyperswarm.mdc): Hyperswarm: P2P networking, peer discovery, and connection management via DHT
- [pear](pear.mdc): Pear OTA runtime, Bare workers, and P2P desktop deployment
- [qvac](qvac.mdc): Local AI session ownership and native adapter boundaries for generated apps.
- [wdk](wdk.mdc): WDK Wallet: crypto wallet and payments integration from Tether
