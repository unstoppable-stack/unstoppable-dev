# Set up a headless runtime

For a new headless target inspect the installed scaffold catalog; Node CLI may be internal-only. Existing Bare services should preserve their runtime boundary. Use the Bare inference adapter for a deliberate local-session integration, not the Node SDK client inside Bare. Inspect installed profile/types and keep native imports lazy. Headless Bare packaging is a separate integration: validate engine/addon compatibility and do not inherit desktop support claims.

Read app metadata first. New targets use the CLI, while upgrades use `us compatibility check -o <app>` and explicit migrations that preserve application files.
