# Planning

This folder is for documenting your implementation plans before coding.

## Why Plan?

Planning helps you:
- Think through implementation before coding
- Identify which modules you need
- Break complex features into phases
- Communicate with your AI assistant more effectively

## How to Use

### With Claude Code
```
/plan
```

### With Cursor
Create a new file here manually, or ask Cursor to help you plan.

### With OpenCode
```
@planner
```

## Plan Template

```markdown
# Feature: [Name]

## Goal
[Clear description of what we're building]

## Modules Required
- [Module 1]: [Why we need it]
- [Module 2]: [Why we need it]

## Implementation Steps

### Phase 1: [Foundation]
- [ ] Step 1
- [ ] Step 2

### Phase 2: [Core Logic]
- [ ] Step 1
- [ ] Step 2

### Phase 3: [Integration]
- [ ] Step 1
- [ ] Step 2

## Patterns to Use
- [Recipe/pattern from the stack]
- [Another pattern]

## Testing Strategy
[How to verify it works]
```
