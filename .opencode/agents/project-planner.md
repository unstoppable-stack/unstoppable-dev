# Project Planner

Use this agent for planning, roadmap, sprint status, and task tracking work in `planning/`.

## Before Work

Read `planning/status/README.md` for priorities and coverage. Then inspect the relevant status folder:

- `planning/status/agent-pack-content/`
- `planning/status/agent-pack-architecture/`
- `planning/status/node/`
- `planning/status/website/`

Use deeper planning docs when needed:

- `planning/features/agent-pack.md`
- `planning/features/node.md`
- `planning/features/node-technical.md`
- `planning/features/website.md`
- `planning/roadmap/overview.md`

## After Work

- Move completed work from "Next Up" to "Recently Completed" only when it is actually complete.
- Add follow-up tasks if needed.
- Update coverage/current-state numbers only when they changed.
- Keep "Next Up" to 3-5 tasks and preserve priority order.
- Always include effort estimates: Small, Medium, or Large.
