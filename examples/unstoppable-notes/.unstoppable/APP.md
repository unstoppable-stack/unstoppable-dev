# Public Notes desktop example

Generated from CLI 0.4.0-beta.4 pear-desktop with no AI features. The app owns its
text-note schema and explicit snapshot exchange; local Hyperbee data is private
and is not automatically replicated. One native node owns scoped invitations
and bidirectional RPC. P2P alpha.4 is the deliberate published dependency pin.
Renderer code uses the context-isolated IPC bridge; native operations stay in
worker.js and src/notebook.js. Read README.md and the test boundaries before
changing behavior. Do not force-regenerate edited app files.
